# Don Juarez Site

Site institucional da Don Juarez Tabaco.

## Estrutura

- `/` — página inicial
- `/sobre/` — marca e origem
- `/produtos/` — produtos
- `/contato/` — atendimento comercial
- `/politica-de-privacidade/` — política de privacidade

## Execução local

Sirva a pasta por HTTP para testar corretamente os caminhos absolutos:

```bash
npx serve .
```

Não abra `index.html` diretamente com `file://`, pois navegadores bloqueiam alguns recursos por segurança.
